# Реставрация объектов — портфолио

Премиальная презентация 16:9 для инвесторов. Направление **E — Full-bleed Editorial**
(выбрано из шести art-direction вариантов A–F): фотография на весь слайд, без рамок
и панелей; узкая полоса-подпись снизу; на слайдах ПОСЛЕ — деталь фасада во врезке
и характеристики горизонтальным рядом.

## Файлы

| Файл | Что это |
|---|---|
| `restavraciya-obektov-E.html` | Готовая презентация. Один файл, шрифты и фото вшиты. Листание — стрелки ← →, на тач-устройствах свайп. |
| `restavraciya-obektov-E.pptx` | Редактируемая версия для PowerPoint (13.333 × 7.5 дюйма). |

Более ранняя версия в другом дизайне (`restavraciya-obektov-Luxury.*`) оставлена в
репозитории для истории, но действующая — `-E.*`.

## Структура — 14 слайдов

1. Обложка — фото на весь слайд, заголовок и подзаголовок снизу
2–13. Шесть объектов парами ДО / ПОСЛЕ
14. Финал — фото + строка-индекс всех шести объектов

Слайд ДО: фото на весь слайд, внизу — узкая тёмная полоса с названием объекта.
Слайд ПОСЛЕ: то же фото на весь слайд, но полоса светлая (ivory) и шире — в ней
появляется блок характеристик (шесть колонок). Справа сверху — врезка с деталью
фасада (там, где для неё есть материал) в тонкой рамке.

Смена тёмной полосы на светлую между ДО и ПОСЛЕ — главный приём: результат
реставрации считывается на уровне цвета, ещё до текста.

Блок характеристик (Площадь здания / Этажность / Год постройки / Состояние /
Статус / Коммуникации) заполнен только названиями — значения оставлены пустыми.

## Замена фотографий

### В PPTX
Правый клик по изображению → **«Изменить рисунок»**. В панели выделения
(Главная → Выделить → Область выделения) слоты подписаны:
`ФОТО-ПЛЕЙСХОЛДЕР — borby-after` и т. п.

### В HTML
Каждый слот — `<div class="hero ph" data-slot="ИМЯ" style="background-image:url(...)">`.
Заменить `url(...)` на новое фото. Пустые слоты помечены классом `ph empty`.

### Пересборка обоих файлов сразу
1. Положить исходное фото в `assets/drive/` (или другую папку)
2. Прописать источник в `build/prepare_e.py` — словарь `HERO` (полный кадр) или
   `DETAIL` (врезка-деталь для слайда ПОСЛЕ)
3. Выполнить по порядку:

```bash
python3 build/prepare_e.py     # кадрирование в 16:9 / деталь
python3 build/build_e.py       # HTML
python3 build/build_pptx_e.py  # PPTX
```

## Проверка

HTML: скриншот каждого слайда, автоматическая проверка на переполнение контента
и выход элементов за пределы слайда — 0 нарушений на всех 14 слайдах.

PPTX: валидация порядка дочерних узлов OOXML (0 нарушений), независимый рендер
сохранённого файла — совпадает с HTML послайдово. 110 редактируемых текстовых
блоков, 18 изображений (15 фото + 3 подписанных плейсхолдера).

## Шрифты

Cormorant Garamond Light (заголовки) и Noto Sans / Noto Sans SemiBold (подписи) —
по белому списку скилла cjl-slides. В HTML вшиты. Для PPTX на машине показа
желательно установить эти же шрифты, иначе PowerPoint подставит замену.
