# Шрифты

`inter-cyrillic.woff2` и `inter-latin.woff2` — подмножества переменного шрифта
**Inter** (кириллица и латиница), полученные из Google Fonts.

Inter распространяется по лицензии SIL Open Font License 1.1:
<https://github.com/rsms/inter/blob/master/LICENSE.txt>

Файлы встраиваются в SVG и HTML, чтобы они выглядели одинаково на любой машине.
PPTX собирается в Arial (см. `PPTX_FONT` в `render_pptx.py`) — в PowerPoint
гарнитуру можно заменить на корпоративную в один приём через «Заменить шрифты».
