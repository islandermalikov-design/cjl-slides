# Альфа-Банк — «Онлайн-продажи», 2 переработанных слайда

Перерисованы два слайда презентации «Онлайн-продажи. Отчет за 8 месяцев 2026 г.»:

| № | Слайд | Файлы |
|---|-------|-------|
| 2 | 5 ключевых источников → 35% онлайн-продаж карт и 19% РКО | `dist/slide-01-sources.*` |
| 3 | Объёмы привлечения: +1,8 млн / +205 млрд руб. / +108 тыс. | `dist/slide-02-volumes.*` |

Содержание не изменено: сохранены все заголовки, формулировки, цифры, проценты,
сноски и порядок блоков. Ни один показатель не удалён, ничего не перенесено
с одного слайда на другой, новых данных и новых смыслов не добавлено.

| `slide-01-sources.png`, `slide-02-volumes.png` | Превью 1920×1080 |

## Что изменилось в композиции

**Слайд «5 ключевых источников».** Пять тяжёлых серых колонок заменены единой
матрицей: белое поле с тонкой рамкой, тонкие линейки между источниками и
строками, подписи строк вынесены в левый столбец. Первый уровень иерархии —
цифры, проценты собраны в компактные зелёные бейджи, единицы измерения и
пояснения приглушены. Список 30+ продуктов вынесен в отдельную светло-серую
панель: три группы, ровные колонки, одинаковый шаг строк, тонкая линейка под
каждым заголовком. Рубин уменьшен примерно втрое и занимает свободную правую
часть панели, ничего не перекрывая.

**Слайд «Объёмы привлечения».** Три показателя — премиальные карточки одного
размера с одинаковой внутренней логикой: крупное число, мелкая единица
измерения, линейка, описание (и приглушённая подпись «КН, КПЗН, МКК» там, где
она есть). Блок «А ещё» превращён в горизонтальный акцентный блок во всю ширину:
кубок слева как второстепенный элемент, вертикальная линейка, «197 млн руб.»,
затем формулировка про запуск игр; правая часть заполнена фирменными тонкими
дугами. Теней нет — глубина даётся лёгкой заливкой и волосяной рамкой.

## Система

```
холст            1920 × 1080 (16:9), поля 80
красный          #EF3124      акцент, цифры
чёрный           #1D1D1D      заголовки и основной текст
зелёный          #2FBD4F      только доли продаж (положительные показатели)
серый текст      #5A5A62 / #8A8A90 / #A5A5AB
линии            #E7E7EB / #DCDCE2
панель / карточка #F6F6F7 / #F5F5F7
акцентный блок   #FDF2F1
радиус           28 (карточки и панели), 14 (бейджи)
```

Шрифт: Inter в SVG/HTML (встроен в файлы), Arial в PPTX — он есть на любой
машине и содержит кириллицу. Чтобы собрать PPTX в корпоративной гарнитуре,
поменяйте `PPTX_FONT` в `render_pptx.py` и пересоберите.

## Сборка

```bash
pip3 install python-pptx fonttools brotli
python3 build.py              # svg + pptx + html
python3 build.py --preview    # плюс PNG (нужен playwright + chromium)
```

| Файл | Роль |
|------|------|
| `spec.py` | вся геометрия и весь текст двух слайдов — единственный источник правды |
| `metrics.py` | метрики шрифта: ширины строк, от которых зависят бейджи и единицы измерения |
| `render_svg.py` / `render_pptx.py` | два рендерера одного и того же спека |
| `build.py` | сборка в `dist/` |
| `assets/` | фирменные элементы (логотип, рубин, кубок, звезда), извлечённые из исходной презентации |

Правка текста или цифры — одна строка в `spec.py`; SVG, PPTX и HTML пересобираются
из неё одинаково, поэтому форматы не расходятся.
