# cjl-slides

24種類の国際的なデザインストールに対応した、視覚的に美しいHTMLプレゼンテーションを作成。.pptx形式への変換も可能。

[English](README.md) | [简体中文](README_zh.md)

---

## 特徴

- **ゼロ依存** — インラインCSS/JSを持つ単一HTMLファイル、npmやビルドツール不要
- **24種のデザインストール** — Pitch、Linear、Swiss、Cyberpunk、Y2K、中国風など
- **PPTXエクスポート** — 生成したHTMLスライドを.pptxに変換し、PowerPointで編集可能
- **反AIスローグ** — 汎用的なAI美学を避けた、独特でDistinctなスタイル
- **厳格なデザインルール** — フォントホワイトリスト、カラー変数、コンテナー比率、チャート標準
