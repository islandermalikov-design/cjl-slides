# HTML slides → PPTX с редактируемым текстом

Конвейер снимает реальную геометрию слайдов из браузера (Playwright) и собирает
PPTX из настоящих фигур и текстовых блоков — в отличие от `../html-to-pptx.py`,
который разбирает HTML статически.

```bash
npm i playwright && pip3 install python-pptx fonttools brotli
node extract.js                              # HTML -> deck.json (правьте путь в файле)
python3 build_pptx.py out.pptx               # deck.json -> PPTX
python3 embed_fonts.py out.pptx final.pptx   # вшить TTF (пути в FONTS)
```

Что переносится: заливки и рамки (включая скругления и пунктир), подсветка
маркером, псевдоэлементы `::before` / `::after` (буллиты, галочки, полоски),
картинки, цвет/размер/начертание/трекинг каждого текстового прогона.

Ключевые моменты:

- слайд 1600×900 px кладётся в 13.333×7.5″, поэтому 1 px = 7620 EMU и 0.6 pt —
  масштаб шрифта обязан совпадать с масштабом геометрии;
- координаты текста берутся не от бокса элемента, а от `Range.getClientRects()` —
  так не сбиваются флекс-отступы и псевдоэлементы;
- строки, разделённые `<br>`, выносятся в отдельные текстовые блоки: положение
  строки перестаёт зависеть от того, как редактор трактует межстрочный интервал;
- у блоков без мягкого переноса выключается `word_wrap`, иначе PowerPoint рвёт
  строки по-своему;
- блоки якорятся по центру по вертикали, а у автофигур удаляется `<p:style>` —
  иначе тема подмешивает тень.
