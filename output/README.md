# Игра как ключевой навык при РАС — минималистичная версия

Переработка презентации ABA & ESDM центра «Ветер» (Щептева Юлия) в минималистичном
стиле: белый фон, крупная типографика, маркер-выделение ключевых слов, светло-сиреневые
и лаймовые акценты.

## Файлы

| Файл | Что это |
|------|---------|
| `igra-pri-ras-minimal.html` | Исходник презентации. Один файл, без внешних зависимостей: шрифты и картинки встроены, работает офлайн. |
| `igra-pri-ras-minimal.pdf` | 47 страниц 16:9 — для показа и печати. |
| `igra-pri-ras-minimal-editable.pptx` | PowerPoint с **редактируемым текстом**: каждый заголовок, список и плашка — обычная фигура PowerPoint. Шрифты вшиты в файл, ставить их не обязательно. |
| `igra-pri-ras-minimal.pptx` | PowerPoint, каждый слайд — изображение: внешний вид гарантированно совпадает с PDF, но текст не правится. |
| `fonts/` | Playfair Display и Noto Sans (TTF). Ставить не обязательно — шрифты вшиты в редактируемый PPTX; установка нужна, только если вы дописываете текст и хотите видеть его тем же шрифтом при редактировании. |

## Навигация в HTML

- `→` / `Space` / `PageDown` — следующий слайд
- `←` / `PageUp` — предыдущий
- `Home` / `End` — первый / последний
- свайп влево-вправо на планшете и телефоне
- `#12` в адресе — переход к слайду 12
- печать из браузера (Ctrl/Cmd+P) даёт тот же PDF, слайд = страница

## Дизайн-система

- Шрифты: Playfair Display (заголовки), Noto Sans (текст) — оба с кириллицей, встроены в файл
- Цвета: `--color-primary #15151B`, `--color-secondary #B9C0EA`, `--color-accent #C7E76A`
- Слайд: `min(100vw, 177.78vh) × min(56.25vw, 100vh)`, все размеры кратны переменной `--w`
  (1% ширины слайда), поэтому вёрстка не ломается на сверхшироких экранах

## Как править

Текст и структура — прямо в HTML: каждый слайд это `<section class="slide">`.
Быстрые правки: `--color-accent` меняет цвет маркера, класс `dense` уплотняет
насыщенный слайд, `.hl` / `.hl-blue` — выделение маркером.

После правок пересобрать PDF и PPTX: печать в PDF из браузера, а PPTX —
конвейером `../scripts/native-pptx/` (снимает геометрию из браузера и собирает
настоящие фигуры PowerPoint), см. README рядом с ним.

Во вставках «ВИДЕО» в PowerPoint: «Вставка → Видео» поверх пунктирной рамки.

## Что перенесено из оригинала

Все 45 исходных слайдов: содержание сохранено, часть длинных абзацев разбита на
списки и цепочки шагов. Схемы «Свободный оперант» и «Как развивается игра» пересобраны
нативной вёрсткой вместо скриншотов. Фотографии слайда «Что мы называем игрой?» и
QR-коды с последнего слайда взяты из оригинала. Слайды с видео помечены рамкой «ВИДЕО».
