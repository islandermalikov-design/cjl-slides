# Интеграции

Все ключи хранятся только на сервере. В UI отображаются лишь последние символы. Без ключей работает DEMO_MODE.

## Anthropic Claude API

- Ключ: `ANTHROPIC_API_KEY` в `.env` (приоритет) или «Интеграции → Anthropic» (шифруется AES-256-GCM).
- Модель: `ANTHROPIC_MODEL` (по умолчанию `claude-opus-5-5`). Включён серверный fallback модели при отказе
  (`fallbacks: "default"`, beta `server-side-fallback-2026-07-01`).
- Ответы — структурированный JSON (`client.beta.messages.parse` + Zod), повторная проверка схемой на сервере.
- Ограничения: `AI_MAX_OUTPUT_TOKENS`, `AI_TIMEOUT_MS`, 2 повтора SDK, rate limit 30 запросов/мин на организацию,
  месячный бюджет (`AI_MONTHLY_BUDGET_USD` или «Настройки → Лимиты»), учёт токенов и стоимости в `AiUsage`.
- Кэш скоринга: повторный анализ с теми же входными данными и моделью не тратит токены (кнопка «Повторный анализ» — принудительно).
- Защита от prompt injection: внешние данные передаются внутри `<untrusted_data>`, закрывающие теги нейтрализуются,
  системная инструкция запрещает исполнять команды из данных, выдумывать факты, кейсы и цифры;
  AI не имеет инструментов и не может отправлять сообщения или менять данные.

## Email (SMTP)

`SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `SMTP_FROM` или «Интеграции → Email (SMTP)».
Отправка выполняется только из центра сообщений после согласования и явного подтверждения. В DEMO_MODE —
симуляция. Для мессенджеров и телефона интеграции нет: сообщение отправляется вручную и подтверждается в системе.

## Collector (apps/collector)

FastAPI-сервис, авторизация заголовком `X-Collector-Token` (`COLLECTOR_TOKEN`, сравнение за постоянное время).

| Метод | Назначение |
|---|---|
| `GET /health` | Проверка доступности (без токена) |
| `GET /adapters` | Список адаптеров и их доступность |
| `POST /discover` | Поиск через адаптер |
| `POST /enrich/website` | Сбор опубликованных данных с сайта компании |
| `POST /robots/check` | Проверка robots.txt для URL |

### Правила сбора

- robots.txt проверяется перед каждой страницей; при недоступности robots.txt (сеть, 401/403) сбор **не выполняется**.
- Пауза не менее 1 с между запросами к одному хосту (или `Crawl-delay`), честный User-Agent.
- Загружаются только главная и одна контактная страница; размер ответа ≤ 2 МБ, таймаут 10 с.
- Email — из `mailto:` и текста страницы на домене компании; телефоны — `tel:` и российские форматы. Ничего не угадывается.
- Не обходятся CAPTCHA, авторизация, антибот-защита.

### SSRF-защита

Разрешены только http/https и порты 80/443, запрещены учётные данные в URL и внутренние имена; DNS-имя
разрешается, и **все** адреса проверяются (loopback, private, link-local, CGNAT, multicast, reserved);
редиректы обрабатываются вручную с повторной проверкой. Остаточный риск — DNS rebinding между проверкой и
соединением; для production рекомендуется выпускать трафик collector через egress-прокси с запретом внутренних сетей.

> В изолированных средах без DNS (например, песочницы CI с HTTP-прокси) сбор с сайтов не выполняется — сервис
> корректно возвращает предупреждение «robots.txt недоступен».

### Адаптеры

| Ключ | Источник | Требования |
|---|---|---|
| `demo` (в веб-приложении) | Синтетический каталог, домены `*.example` | — |
| `website` | Сайты из списка URL | — |
| `yandex_search` | Яндекс Search API v2 (Yandex Cloud): сайты по нише и городу → сбор контактов с сайтов | `YANDEX_SEARCH_API_KEY`, `YANDEX_FOLDER_ID`; платный API; агрегаторы, соцсети и маркетплейсы исключаются |
| `2gis` | Places API 2ГИС: организации по нише и городу с адресом и контактами | `TWOGIS_API_KEY`; проверить условия тарифа (хранение данных, доступность `contact_groups`) |
| `dadata` | API подсказок DaData (организации по названию/ИНН) | `DADATA_API_KEY` в окружении collector; адаптер написан по документации API, на живом ключе в рамках разработки не проверялся |

**Новый источник:** класс-наследник `Adapter` в `app/adapters/`, регистрация в `registry.py`, тесты с `respx`.
Перед активацией в UI («Источники данных») необходимо указать основание использования и подтвердить проверку
robots.txt и условий использования.

### Маркетплейсы

Официальные API Wildberries и Ozon предназначены для работы продавца **со своим** кабинетом и не предоставляют
поиск сторонних продавцов — поэтому они не используются как источник лидов. Покупательские чаты для рекламы не используются.

> Адаптеры `yandex_search` и `2gis` проверены только на подставных ответах (в среде разработки нет ключей и доступа к документации 2ГИС); при первом запуске с реальным ключом сверьте формат ответа.
> Google Programmable Search не используется: API закрыт для новых клиентов.
