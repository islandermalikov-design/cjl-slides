## Проверено в последнем запуске

- `pnpm lint`, `pnpm typecheck` — без ошибок.
- `pnpm test` — 13 тестов shared + 43 unit/интеграционных теста web (PostgreSQL).
- `pnpm test:e2e` — 7 Playwright smoke-тестов.
- `uv run pytest` (collector) — 25 тестов; `ruff` — чисто.
- `pnpm build` — успешная production-сборка.
- Worker BullMQ: задание из очереди выполнено отдельным процессом.
- Docker: образы collector и web (worker, standalone runner) собраны и запущены; шаг установки Chromium в runner-образ
  не проверен в изолированной среде разработки (apt через прокси недоступен).

## Известные ограничения

- Сбор с реальных сайтов и адаптер DaData не проверены на живых данных в среде разработки (нет DNS/ключа);
  логика покрыта тестами с моками HTTP.
- AI-генерация с реальным ключом Claude не запускалась (ключ не предоставлялся); путь DEMO и обработка ошибок
  (нет ключа, бюджет) покрыты тестами.
- Приглашение пользователей по email не реализовано: администратор добавляет уже зарегистрированного пользователя.
- Одна организация на пользователя в интерфейсе (переключатель организаций — в планах).
- Входящие ответы фиксируются вручную (нет IMAP-интеграции).

## Следующие шаги

1. IMAP-интеграция для автоматического получения ответов на email (с привязкой по `X-LeadFlow-Message`).
2. Приглашения по email и переключение между организациями.
3. Вебхуки/уведомления о просроченных задачах (email/Telegram-бот для владельца, не для клиентов).
4. Шаблоны КП с собственным брендированием (логотип, цвета) и вложение PDF в email.
5. Дополнительные адаптеры источников (после юридической проверки условий использования).
6. Отчёт по расходам на AI по функциям и пользователям; выбор модели для отдельных сценариев.
7. Нагрузочное тестирование и индексы под большие базы (>100 тыс. компаний), полнотекстовый поиск (pg_trgm).
