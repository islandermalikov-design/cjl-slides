# Безопасность

| Требование | Реализация |
|---|---|
| Авторизация | Better Auth (email + пароль, scrypt-хэш), сессии в БД, httpOnly cookies, `Secure` в production, SameSite=Lax |
| Разделение прав | Роли OWNER / ADMIN / MEMBER / VIEWER; `requireContext(role)` в каждом server action и API-маршруте |
| Проверка доступа на сервере | `proxy.ts` — только оптимистичный редирект; реальная проверка сессии и роли — в обработчиках |
| Tenant isolation | `organizationId` из сессии во всех запросах; проверка принадлежности связанных записей; интеграционные тесты `tenant-isolation.test.ts` |
| Валидация | Zod-схемы для всех входных данных (общие в `packages/shared`) |
| Rate limiting | Better Auth (вход 10/мин, регистрация 5/5 мин); `rateLimit()` (Redis или память) для поиска, импорта, AI, отправки, экспорта |
| SSRF | Синтаксическая проверка URL в веб-приложении; DNS-проверка всех адресов и ручные редиректы в collector |
| Загрузка файлов | Только CSV/XLSX, ≤ 5 МБ, ≤ 10 000 строк, проверка сигнатуры ZIP для XLSX, обработка в памяти без сохранения на диск |
| CSV formula injection | Очистка ячеек при импорте, экранирование `= + - @` при экспорте |
| Prompt injection | Внешние данные в `<untrusted_data>`, нейтрализация тегов, AI без инструментов, проверка `companyId` в предложенных действиях |
| XSS | React-экранирование; HTML КП строится с экранированием всех значений, превью — в `sandbox`-iframe с CSP `default-src 'none'`; PDF-рендер без JS и без сети |
| Секреты | AES-256-GCM для ключей интеграций; ключи не отдаются клиенту; `redact()` в логах и аудите |
| Заголовки | `X-Content-Type-Options`, `X-Frame-Options: DENY`, `Referrer-Policy`, `Permissions-Policy` |
| Audit log | Удаление, экспорт, импорт, отправка, согласование, интеграции, роли, suppression list |
| Коммуникации | Обязательное согласование, явное подтверждение отправки, основание обращения, suppression list, лимиты, запрет повторов без ответа |
| Резервные копии | `scripts/backup.sh` / `restore.sh` |
| Экспорт и удаление | JSON-экспорт организации, удаление компании/DEMO-данных/организации |
| Зависимости | Версии закреплены lock-файлами; выбраны релизы старше 2 недель; `pnpm audit --prod` и `pip-audit` — без известных уязвимостей. Dev-зависимость `braces` (через eslint-config-next) имеет advisory без исправленной версии — используется только линтером на собственных шаблонах путей |
