# Круглый стол МСЭО — «Залог не начало разговора»

Итоговая презентация: **`Круглый-стол-МСЭО-2026.pptx`** (32 слайда, 16:9, 13.333×7.5″).
Полностью редактируемая — все объекты нативные PowerPoint (текстовые рамки,
автофигуры, картинки), без растровых «картинок-слайдов».

## Что откуда взято

| Источник | Что использовано |
|---|---|
| Черновик сценария (27 слайдов) | весь контент, цифры, вопросы модератора, источники |
| Сайт «Форум риск-менеджеров 2026» (рисковики.рф) | фиолетовый градиент титула и разделителей, фуксия-акцент, пилюли-бейджи с датой и площадкой, кольцевая графика |
| Визитки МСЭО (PDF) | логотип в кривых → вектороподобные PNG с прозрачным фоном (`assets/`), фирменные navy + бирюза, контакты для финального слайда |

## Структура

1. Титул
2. **Блок 01** · 0–15 мин — где накапливается риск (слайды 2–8)
3. **Блок 02** · 15–35 мин — отраслевые кейсы: Wildberries, «Трасса», уголь, металлургия (9–17)
4. **Блок 03** · 35–70 мин — четыре слоя риска, цепочка MV → NPV Recovery, водопад recovery, залоговая функция (18–21)
5. **Блок 04** · 70–90 мин — вопросы залу, тайминг, финальный тезис, дисциплина данных (22–24, 27)
6. Приложение — источники (25–26) и контакты МСЭО

Добавлено к черновику: 4 слайда-разделителя, слайд контактов, а также
диаграммы вместо списков — горизонтальные бары (реструктуризация по отраслям),
водопад recovery (1 000 → 495 млн против долга 667 млн), лента тайминга на 90 минут.

## Дизайн-система

```
--violet-deep  #240D4E   фон титула, разделителей, тёмных плашек
--violet-mid   #5B21A8   конец градиента
--magenta      #E21CA8   основной акцент (сайт форума)
--magenta-hi   #FF5CD2   светлый акцент на тёмном
--teal         #2A8DB6   фирменный цвет знака МСЭО
--navy         #262E41   основной текст, шрифтовая часть логотипа МСЭО
--slate        #5E677D   вторичный текст
--lilac        #F6F2FC   фон светлых страниц
```

Шрифты: **Segoe UI / Segoe UI Semibold** — заголовки, цифры, текст;
**Georgia** (курсив) — вопросы модератора и цитаты. Оба есть в стандартной
поставке Windows и Microsoft Office. Чтобы сменить — правьте `F_HEAD`,
`F_BOLD`, `F_SER` в `deck_core.py` и пересоберите.

## Пересборка

```bash
pip3 install python-pptx
cd presentations/mseo-roundtable
python3 build.py
```

- `deck_core.py` — палитра, типографика, низкоуровневые помощники (градиенты, тени, прозрачность, разрядка)
- `deck_layouts.py` — шаблоны страниц: титул, разделитель, метрики, строки, сетка, бары, вопросы
- `deck_special.py` — штучные слайды: слои риска, цепочка стоимости, водопад, тайминг, источники, финал, контакты
- `build.py` — весь контент презентации
- `assets/` — логотип МСЭО: `logo_color/white.png` (полный), `mark_color/white.png` (только знак)

## Что стоит проверить перед показом

- Дата и площадка на титуле («22 сентября 2026 · QUATTRO SPACE, Москва») взяты
  с сайта форума — подставьте фактические реквизиты круглого стола, если они иные.
- Слайд 20 — иллюстративная модель NPV, а не оценка объекта (помечено на самом слайде).
- Тезис «залог покрывает не более 50% портфеля» намеренно оставлен гипотезой (слайды 7 и 27).
