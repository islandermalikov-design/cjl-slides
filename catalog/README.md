# Каталог спецтехники Irbis

Одностраничный каталог: 7 товарных групп, 45 моделей. Ключевые характеристики
по каждой группе, полные спецификации, ссылки на карточки поставщиков,
слоты под фотографии и реестр расхождений в данных.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Готовый каталог. Открывается двойным кликом, работает офлайн. |
| `Каталог_Irbis.xlsx` | Те же данные таблицей — с автофильтром, для КП и прайсов. |
| `data.py` | **Единственный источник данных.** Правки вносить здесь. |
| `build.py` | Пересборка: `python3 build.py` → `index.html` + `.xlsx`. |
| `style.css`, `app.js`, `svg_art.py` | Оформление, поиск/фильтры, контурные схемы машин. |
| `photos/` | Фотографии. См. `photos/README.md`. |
| `fetch_photos.py` | Скачивание фото со страниц поставщиков (нужен интернет). |

## Как добавить фото

Положить снимок в `photos/<код>.jpg` — карточка подхватит его автоматически
и заменит контурную схему. Пересборка не нужна. Коды — в `photos/README.md`.

Массово: `pip install requests beautifulsoup4 pillow && python3 fetch_photos.py`.
Скрипт берёт крупнейшее изображение со страницы товара и кадрирует под 16:10;
результат обязательно просматривать глазами.

## Как править характеристики

В `data.py` у каждой позиции три «ключевых» параметра группы (`key`) и
произвольный список прочих (`specs`). Третий элемент строки `"tbd"` помечает
значение как неподтверждённое — в каталоге оно выводится курсивом со знаком «?»
и попадает в счётчик «к уточнению». После правок: `python3 build.py`.

## Полнота данных

Характеристики сверены по дилерским каталогам XCMG, SEM и NHL/Terex.
Позиции с расхождениями или без подтверждения в открытых источниках собраны
в блоке «Расхождения и открытые вопросы» внизу страницы — до подтверждения
у поставщика не выносить в коммерческое предложение.
