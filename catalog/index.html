Расхождения и открытые вопросы

Позиции, где данные исходной таблицы расходятся с каталогами поставщиков либо отсутствуют в открытых источниках. До подтверждения не выносить в коммерческое предложение.

  1. Irbis IR5505Один из самых тяжёлых серийных автогрейдеров в классе.
  2. Irbis IR-TR60В исходном файле обозначен как IR3207K — этот индекс уже занят телескопическим погрузчиком. Требуется развести обозначения.
  3. Irbis IR3090FОткрытые источники не дают подтверждённых характеристик. Данные запросить у поставщика.
  4. Irbis IR8010KВ исходном файле масса указана 15,5 т, у производителя — 14,1 т. Уточнить исполнение.
  5. Irbis IR23010KВ исходном файле: масса 23 т, грузоподъёмность 32,8 т. По логике индекса значения переставлены местами — грузоподъёмность 23 т при массе 32,8 т. Требует подтверждения.
